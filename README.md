# 📂 Project 04 — Assignments (Python Projects Collection)

A curated collection of small, beginner-friendly **Python** assignments and example projects designed to teach core programming concepts (variables, expressions, conditionals, loops, lists, dictionaries, simple games, and more). It’s a great learning playground for students and newcomers who want hands-on practice building small utilities and games.

---

# ✨ Highlights

* 🧭 **Well-organized learning path** — Projects grouped by topic and difficulty (intro → expressions → lists → conditionals → loops). 
* 🧩 **Many small, focused projects** — Each script focuses on 1–2 concepts (e.g., converters, simple games, list/dict exercises). 
* ⚙️ **Minimal dependencies** — Most projects run with **Python 3.x** and do not require external libraries. 
* 🎮 **Includes classic CLI games & demos** — Mad Libs, Guess the Number, Rock-Paper-Scissors, Hangman, countdowns, joke bot, etc. 
* 📚 **Good for teaching & portfolios** — Small, readable programs that are easy to adapt, extend, and showcase.

---

# 🗂 How this repo is organized

Top-level folders group projects by purpose and where they came from:

* `homework_projects/` — topic-based homework assignments

  * `00_intro_python/` – basic I/O, arithmetic, variables.
  * `01_expressions/` – expression & string formatting exercises.
  * `02_lists/` – list operations and mutability practice.
  * `03_if_statements/` – branching and conditional logic.
  * `04_dictionaries/` – basic dict usage and lookups.
  * `05_loops_control_flow/` – loops, repetition, and control flow. 

* `online_class_projects/` — example projects shown in class (simple games, small demos). 

* `projects_to_be_submitted_by_students/` — slightly larger themed student projects to implement and submit (Mad Libs, Guess the Number variants, Rock-Paper-Scissors, Hangman, Countdown Timer, etc.).

# 🚀 Quick start — run any project

1. Clone the repo:

   ```bash
   git clone https://github.com/HasnainDevMaster/Project_04_Assignments.git
   cd Project_04_Assignments
   ```

2. (Optional but recommended) Create & activate a virtual environment:

   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS / Linux
   source venv/bin/activate
   ```

3. Most scripts require **only Python 3.x** — no extra packages needed for core exercises. If a project does require a dependency, the project folder will typically document it. 

4. Run a script:

   ```bash
   # example — replace with the real filename you want to run
   python homework_projects/00_intro_python/example_script.py
   ```

   * Many projects are interactive (asks for user input) — run them from a terminal/console.
   * Games will typically read from `input()` and print to stdout.

# 🧭 Recommended learning path

Start from the top (easy → harder):

1. `homework_projects/00_intro_python/` — basic I/O and arithmetic
2. `homework_projects/01_expressions/` — string formatting & calculations
3. `homework_projects/02_lists/` — list operations
4. `homework_projects/03_if_statements/` & `04_dictionaries/` — branching and lookups
5. `homework_projects/05_loops_control_flow/` — loops and repetition
6. Try `online_class_projects/` demos, then implement a `projects_to_be_submitted_by_students/` challenge (Mad Libs, Hangman) to consolidate learning. ([GitHub][2])
